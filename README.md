# Kidslink Children's Clinic Website

This repository hosts the custom-coded website for **Kidslink Children's Clinic**, a specialized pediatric medical practice with branches in Bedok, Choa Chu Kang, Jurong, and Sengkang, Singapore.

## Project Overview

This project represents a migration from a previous Wix-based site to a performant, custom solution. The primary goal is to provide a static, single-page experience that is identical to the original design but optimized for modern web standards.

- **Live URL**: [www.kidslink.com.sg](https://www.kidslink.com.sg)
- **Maintainer**: Jin Hao Hong

## Tech Stack

- **Core**: HTML5, CSS3, Vanilla JavaScript (No backend required)
- **Hosting**: Vercel (Optimized for static site delivery)
- **Analytics**: Google Analytics 4, Vercel Analytics

## Key Features

1.  **Mobile-First Architecture**: Designed primarily for mobile users (approx. 80% of traffic).
2.  **"Call Now" Floating Bar**: A sticky footer action bar specifically for touch devices to facilitate quick contact.
3.  **Single Page Layout**: A seamless, scrollable experience featuring four main sections:
    - Welcome / Introduction
    - Team (Doctor descriptions)
    - Opening Hours
    - Contact Details (with embedded interactive Google Maps)
4.  **SEO Optimization**:
    - Comprehensive Schema Markup for multiple clinic locations.
    - OpenGraph and Twitter Card integration for social sharing.
    - Optimized meta tags and semantic HTML structure.
